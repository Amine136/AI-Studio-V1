1. PLAIN CHAT

Plain chat no longer builds a transcript prompt in the frontend.

Current flow:
- frontend creates or loads a persisted conversation
- frontend sends structured message parts to:
  /chat/conversations/{conversation_id}/messages
- backend loads recent stored messages from the database
- backend assembles a bounded context window
- backend sends canonical messages[] to ApiKeyManager /api/v1/chat

Important note:
- frontend plain chat no longer uses /generate
- frontend plain chat no longer sends requested_outputs: ["caption"]
- frontend plain chat no longer uses buildConversationPrompt(...)
